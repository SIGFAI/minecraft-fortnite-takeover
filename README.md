# Fortnite Takeover

**Minecraft** × Fortnite · visual · idea by the team

Bring Fortnite into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned Minecraft into a battle royale: Battle Bus, banana bots gliding in, a Loot Llama and a closing storm. Walling up vs a shotgun is chaos.

## Install

Copy the mod jar into your Fabric mods folder for Minecraft Java 26.3 (needs Fabric Loader and Fabric API). Start a world: the Battle Bus flies in and the match begins. Open the Loot Llama, grab the shotgun, shield potions and build tool, then right-click to shoot, drink or build.
